# Week 1 Blender Workshop – Delivery Checklist

## ✅ Setup & Navigation (10 mins)

### Interface Tour

- Viewport = modelling area
- Outliner = object list
  - Cube
  - Camera
  - Light
- Properties Panel
  - Object Properties
  - Materials
  - Modifiers
  - Render Settings
- Timeline = animation
- Workspace tabs = rearrange interface

### Important

- Z = Up
- Save often

### Navigation

#### Mouse
- MMB = Rotate
- Mouse Wheel = Zoom
- Shift + MMB = Pan

#### Trackpad
- Alt + LMB = Rotate
- Alt + Ctrl + LMB = Zoom
- Alt + Shift + LMB = Pan

> ## 🎯 Student Task 1
>
> - Open Blender
> - Create a Blender folder
> - Save as `Practice.blend`
> - Orbit around the cube
> - Zoom in and out
> - Pan around the scene
> - Locate:
>   - Viewport
>   - Outliner
>   - Properties Panel

- Shift + A

### Move

- G

- G Y
- G Z

### Rotate

- R
- R X
- R Y
- R Z

### Scale

- S
- S X
- S Y
- S Z

### Precision

- Hold Shift

### Useful Panel

- N
- Location
- Rotation
- Scale
- Dimensions
